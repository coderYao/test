Renders a portal preview video offline, frame by frame: the real game stepped at a fixed 60 Hz while a scripted brush plays it, so the result is identical on any machine and carries no system cursor. It opens on the cover image and fades into play.

?format=landscape (1920×1080) or ?format=portrait (1080×1620), &seconds=18. Add &post=http://localhost:8002 to send frames to tools/collect_frames.py, which encodes the MP4 with ffmpeg; without it the page just plays the take through. &dry=1 skips rendering and prints the run log, for tuning the choreography.
